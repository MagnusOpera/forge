Keyboard shortcuts · macOS

Stay in flow.

⌘ means Command and ⇧ means Shift. Plain navigation keys apply outside text fields; the terminal keeps its own key handling, and dialogs temporarily take precedence.

Project views cycle in this order: Codex, Pull Requests, Workflows, Issues, Workflow Runs. The current bindings use ← for the next view and → for the previous view.

Detachable windows

Keep a task in view.

Use Detach content pane in the content toolbar to move a conversation, pull request, issue, workflow run, or workflow into its own native window. Narrow toolbars may place it in the overflow menu.

Press ⌘⇧D to detach the current content pane. Use the same shortcut in its detached window to reattach it. It also works while editing a message; dialogs and the command palette take precedence.

Reattach or close.

Use Reattach content pane to bring the item back and select it in the main workspace. Closing the detached window with its close button or ⌘W also returns its content, while preserving the main window’s current selection.

Keep your place.

The live content moves between windows, preserving drafts and view state. Other items stay available in the main workspace, and you can detach multiple items independently. Codex turns and terminal sessions continue when a detached window closes.

Codex workspace

Choose where to work.

Install a compatible Codex CLI and sign in through global configuration. Open global configuration from the gear in the expanded repository sidebar; the gear beside a project’s name opens project configuration.

Checkouts and environments.

Configure a local Git checkout or an SSH environment in project configuration. Before a thread starts, choose an isolated worktree, the default branch, a new named branch, or the current branch.

Find earlier work.

The search button beside New thread searches titles and user/assistant messages stored in Forge. Results are ranked with excerpts; Active and Archived filter the results. Escape closes the search.

Review and integrate.

Inspect changed files and diffs, then review a squash merge or merge into the default branch. After successful local integration, Forge removes the clean merged worktree and continues the same chat on the default checkout.

For account settings, permissions, terminal behavior, and remote-host setup, see the full workspace guide.
