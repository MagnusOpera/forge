Plan, then implement.

Review what changed.

Follow command output and file changes, inspect unified or split diffs, and open the worktree in your editor. Use Git quick actions when you’re ready to commit, push, or create a pull request.

A terminal for every thread.

Open an integrated terminal in the thread’s checkout. For work on another machine, connect Codex to your own environment over SSH.
